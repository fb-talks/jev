What is it and Why use it?Agent Developer Kit

An open-source framework (Apache 2.0) for building AI agents that supports Python (which we'll use), Go, and Java.

1The "Polymorphism" BenefitADK forces you to stick to a unified interface, which makes swapping out components a breeze.
2Kit toolA mix of tools (prebuilt and custom) to create agents that range from deterministic to non-deterministic ones.
3OrchestrationCompose small, specialized agents into complex, hierarchical systems.
4State ManagementRaw LLM APIs are stateless; ADK tracks, stores and updates an agent's data, context, progress and memory across steps.
